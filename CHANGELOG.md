# Changelog

All notable changes to this project will be documented in this file.

This project follows a simple versioning approach while it is experimental:

- `0.x` versions may include breaking changes.
- `1.0.0` will mean the way people use the script is considered stable.

## 0.2.1 - 2026-08-24

- Updated GitHub ownership and public URLs after the account rename.
- Updated jsDelivr examples and package metadata to use the new GitHub username.
- No runtime behavior changes.

## 0.2.0 - 2026-07-10

- Added optional mobile layout scaling with a dedicated design width and breakpoint.
- Added support for shared wrappers with mobile CSS, or separate desktop and mobile wrappers.
- Added the active layout marker on `<html>` as `data-responsive-scale-layout`.
- Updated the basic demo and documentation with a two-layout example.

## 0.1.0 - 2026-06-24

Initial experimental release.

- Added automatic scaling for fixed-width layouts.
- Added support for fixed elements with `data-scale-fixed`.
- Added corrected body height after CSS transforms.
- Added data attribute configuration.
- Added manual initialization method.
- Added basic demo.
